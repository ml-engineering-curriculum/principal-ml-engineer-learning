# mod-501-principal-ml-role-scope: The Principal ML Engineer Role: IC-Principal Altitude, Titles, and the Distinguished-vs-Principal Boundary

**Estimated effort:** 8 hours

Everything downstream in this track — the multi-year North Star (mod-502), the north-star architecture (mod-503), cross-org influence (mod-504), the technical bar (mod-505), and industry voice (mod-506) — presupposes that the learner already knows what a Principal ML Engineer *is* and, just as importantly, is *not*. This module builds that vocabulary and draws that boundary. It grounds every claim in the verb-and-object table and the 26-posting sample catalogued in [`../../JOB_REQUIREMENTS.md`](../../JOB_REQUIREMENTS.md) — no invented facts, no aspirational role fiction.

Read the chapters in order; each one narrows the definition further, from generic "senior engineer" all the way down to the specific IC-principal altitude this track owns.

## Learning objectives

- Articulate what a Principal / Sr. Principal / Distinguished / Sr. Distinguished Machine Learning Engineer owns end-to-end vs. what a Staff ML Engineer (L40) owns beneath and what a Head-of-AI / VP-of-ML / CAIO owns on the peer executive branch — using the verb-and-object table (`set` the ranking model → the portfolio → **the ML org's technical direction across product areas**) as the vocabulary.
- Read a Principal / Distinguished ML posting and identify the principal-defining verbs — 'set the technical North Star for ML', 'define the multi-year modelling roadmap', 'north-star platform architecture with living diagrams and canonical APIs', 'influence cross-functional stakeholders up to the SVP level', 'multiply the effectiveness of every ML team' — and distinguish them from Staff verbs and from executive-track verbs.
- Draw the boundary between the three level-48+ role families: Principal ML Engineer (this track, IC — no direct reports), Head-of-AI / VP-of-ML / Chief AI Officer (peer executive path, owned by `chief-ai-officer-learning` and `head-of-ai-governance-learning`), and Principal Research Scientist / Distinguished Applied Scientist (peer research path). Name which family a given posting belongs to and why.
- Write a self-assessment placing the learner against the four principal-scope themes (`req-org-industry-strategy`, `req-applied-ml-architecture`, `req-cross-org-influence`, `req-principal-mentorship-and-bar`) — where the learner has lived experience already and where the level-up work is.
- Author the hand-off contracts back to staff-plus IC scope owned by `staff-ml-engineer-learning` (multi-team blueprint, foundation-model program, distributed-training program, portfolio TCO, portfolio-scope responsible-AI, staff-plus tech leadership) — the principal must not re-do that scope, only lift it.
