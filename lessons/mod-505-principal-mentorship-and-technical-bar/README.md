# mod-505-principal-mentorship-and-technical-bar: Principal Mentorship & Technical-Bar Calibration for the ML Org

> Scaffolded by `aicg org execute-plan`. Lecture chapters and exercise content are authored on subsequent autonomous cycles.

**Estimated effort:** 12 hours

## Learning objectives

- Coach staff engineers (L40) — not senior tech leads (that scope is owned by `staff-ml-engineer-learning` mod-410 exercise-04). Set the growth conversation for a staff IC deciding between principal-IC path, engineering-manager path, and specialist-track path — and be able to name what the learner would need to see before endorsing each
- Multiply the effectiveness of every ML team in the org — per Upstart's principal role definition. Identify the small number of leverage moves (a canonical review pattern, a north-star architectural revision, a bar-raising interview change, a shared eval standard) that lift the whole org rather than one team
- Calibrate the technical bar for the ML org at staff-plus altitude: sit on staff-plus hiring loops (loop-level calibration, not just individual interviews — the staff-scope hiring loop is owned by `staff-ml-engineer-learning` mod-410 exercise-03), decide the bar between hire / no-hire / staff-vs-principal, and coach the loop chair on running rubric-based principal-track interviews
- Set the code / architecture review bar the ML org calibrates against: the required rigor for a portfolio-scope RFC, the required rigor for a north-star architectural revision, and the escalation path when a lower-level review needs principal weight to unblock
- Elevate engineering culture without sliding into people-management scope — per Bumble 'operate as a senior individual contributor... without direct authority' and Ibotta 'act as a leading contributor, voice, and thought leader in a growing community of machine learning practitioners' (internal community). The principal owns the technical-culture leverage; the engineering-manager peer (`ai-infra-team-lead-learning`) owns headcount and performance reviews
- Sustain the principal signal over years: name the failure modes (drifting into IC-only work, drifting into management, drifting into keynote-only work, chasing every bet at once) and set the personal-cadence artifact — quarterly and yearly — that the principal reviews to stay in the archetype
